# 暮林倖存者 · Lineage Survivor

原創黑暗奇幻瀏覽器生存遊戲，繁體中文介面。以經典奇幻職業與 survivor 自動戰鬥節奏為靈感，**不是《天堂》的官方產品**，未使用其角色、地圖、音樂或美術資產。

## 遊玩

私人線上版：https://lineage-survivor-dcvsling.dcvsling.chatgpt.site （須以擁有者帳號登入）

或在此目錄啟動靜態伺服器：

```sh
python3 -m http.server 8080 --directory dist
# 開啟 http://localhost:8080
```

不需安裝 npm 套件；需現代瀏覽器及支援 ES modules 的 HTTP 伺服器，不能直接以 file:// 開啟。

- **WASD / 方向鍵**：移動。手機使用左下搖桿；可按頂端「觸控」手動顯示搖桿與右側技能按鈕。
- **空白鍵 / 職業技按鈕**：騎士王者守護（擊退、3秒減傷，12秒冷卻）、遊俠疾風閃步（沿移動方向短衝刺及短暫無敵，10秒冷卻）、法師霜星新星（範圍傷害與緩速，14秒冷卻）。
- **自動攻擊**：騎士月鋼斬、遊俠風靈箭、法師追蹤焚星術。
- **Q / 治療按鈕**：恢復 45% 最大生命，每局 3 瓶；滿血不消耗。
- **Esc / 暫停按鈕**：暫停、繼續、放棄返回營地。切離視窗自動暫停。
- 翠綠靈魂提供經驗，升級會停止時間並提供三選一祝福。主武器、聖焰環及雷霆誓約於第五階進化。
- 第七分鐘君王出現；**擊倒君王且存活滿八分鐘**勝利。八分鐘仍未擊倒則「黎明撤離」，不是死亡或勝利；本局準時結束並保留一般戰利品。
- 死亡、勝利與撤離均結算：至少擊倒 35 隻魔物可得 +1 裝備、存活四分鐘可得 +2、擊倒君王可得 +3。隨機一個欄位，保留較高階；自動裝備至下一局。武器每階 +8% 傷害、鎧甲每階 +10 生命及減傷 1、戰靴每階 +5 移速。金幣可在營地鍛造裝備，費用為 100 × 下一階²，最高 ＋5。
- 傳承保存在目前網站來源的 `localStorage`，無伺服器、帳號同步或追蹤。保留原 v1 存檔 key；1.5 起格式升為 schema 2，自動讀取舊版資料；增加前次有效存檔備援，損毀時嘗試復原；較新版存檔拒絕覆寫。營地「存檔備份」可複製或匯入 JSON 備份碼，匯入需二次確認。換瀏覽器、換網址或清除網站資料會失去進度。儲存受阻時會提示並保留記憶體中的本次進度。

## 驗證

Node.js 20+：

```sh
npm test
npm run check
npm run soak # 36 個正常生命條件的長局壓力測試，本機約 20 秒
```

95 個模擬、指令、鍛造與儲存測試涵蓋：職業差異、移動邊界與正規化、暫停、三選一防重入、進化、有限治療、死亡與重開、裝備、遠程攻擊、固定種子重現、八分鐘效能界線及**正常生命與藥水條件的完整遊俠勝利**。最後一項使用固定種子自動走位測試，不是無敵模式。另有桌面瀏覽器 UI 驗證；觸控搖桿可用桌面指標測試，但尚未完成 Android/iOS 實機或觸控模擬驗證，不代表手機認證。

GitHub Actions 在 push 與 pull_request 執行同一組檢查。不需秘密、外部 API 或後端。

## 結構

- `dist/engine.js`：純 JavaScript、無 DOM 的固定種子遊戲模擬。
- `dist/renderer.js`：原創 Canvas 像素森林、角色、敵人、粒子。
- `dist/save.js`：版本化、輸入驗證與錯誤復原的本機傳承儲存。
- `dist/save-transactions.js`：讀取最新進度的序列化鍛造／匯入／結算交易。
- `dist/input.js`：單一觸控指標擁有權及鍵盤輸入過濾。
- `dist/progression.js`：純函式鍛造交易與費用。
- `dist/console.js`：唯讀遠征查詢（保留先前遠端新增的模組）。
- `dist/main.js`：介面、鍵盤/搖桿、音效、傳承紀錄。
- `dist/style.css`、`dist/index.html`：響應式介面。
- `tests/*.test.js`：自動化邏輯與八分鐘回歸。
- `.openai/hosting.json`：私人 Sites 靜態部署設定；不含憑證。

## 1.1：遠征與傳承

在 v1 基礎加入三種主動職業技、金幣鍛造、存檔備援/匯出/確認匯入，並將既有唯讀指令模組接入暫停選單。指令只接受 help/status/player/skills，無 eval、任意程式執行或存檔修改。地圖怪物上限修正為嚴格180，滿額仍保留君王生成。

## 1.2：看見危機

- 遠程敵人與君王先顯示橘色虛線瞄準 0.6 秒，鎖定方向後才發射；暫停會一起凍結預警。君王九發扇形彈幕與預警方向相同。
- 小鬼、獵犬、披袍術士及鹿角君王具備不同輪廓；受擊閃爍、減速顏色、武器／光環進化外觀更易辨認。
- 新玩家第一次出發前會看到可取消的指南；營地和暫停畫面可再次查閱。
- 新增預警時序／鎖定／暫停測試及390／1188寬度的Canvas呼叫煙霧測試；後者不等於行動裝置實測。

## 1.3：有始有終

- 每局最多 **480秒**。最後一個有限模擬步內先處理戰鬥，若仍存活且君王已倒下就勝利；未擊倒則撤離。不會因原地繞圈而無限延長。死亡與君王被擊倒的先後順序有回歸測試，死亡後不再擊殺。最後一個模擬步可同時達成擊倒君王與迎接黎明。
- 結算明確顯示近戰／飛射傷害來源、最後損失生命、勝利條件或撤離原因與建議。
- 支援 Web Locks 的瀏覽器將所有鍛造、匯入及結算鎖在同一個跨分頁交易中，讀最新金幣再操作，裝備取最高階，避免舊分頁覆寫已購裝備。取得鎖最多等待3秒；失敗或空間不足時，戰利品保留於本頁記憶體並提示匯出，不會假裝已儲存。
- 沒有 Web Locks 的環境採讀寫快照檢查，**不保證跨程序原子性**；建議只開一個遊戲分頁。偵測到衝突時不覆寫其他分頁，並提示重試／備份。本機資料仍無跨裝置同步。
- 不相容版本的原始存檔可以完整複製，不再將空白預設值誤當備份。若同時有本頁試玩戰利品，會另列不同備份碼。匯入有確認步驟，儲存是否成功明確顯示。
- 搖桿只接受目前擁有者指標，其他手指不能搶走或取消它；切離視窗釋放輸入。視窗內的空白鍵保留標準按鈕操作，不再被職業技攔截。

### 新角色節奏觀察（非玩家難度排名）

固定種子7／42／2026、零裝備、自動走位的觀察：遊俠與法師約60秒L6、120秒L9、240秒L15–17；騎士約60秒L3–6、120秒L5–9、240秒L9–17，對靠近敵人／經驗的路線更敏感。原本未結束的騎士種子42在240秒後遠離敵群繞圈，敵人上限已滿，君王也被甩在遠處；這不是君王死亡判斷失效。這版只收斂終局與提示，沒有為了讓機器勝利而更改傷害、移速或怪物強度。

## 可靠性檢查

`npm run soak` 重現三職業 × 三固定種子，使用正常生命、治療與主動技，檢查數值有限、敵人/彈幕/掉落/效果上限、終局獎勵及終局不可再變動。測試機觀察約5秒、取樣Node heap約31MiB；不是手機FPS或完整記憶體效能認證。7局通關、1局法師陣亡、1局騎士於480秒撤離，沒有無限延長的局；機器走位的勝率不當作玩家平衡結論。

1.2亦修正致命傷後同一影格仍可擊殺敵人、導致結算與畫面不一致的問題，並把終局彈幕/效果限制在既有上限。

## 目前範圍與限制

單一森林、三職業、三類小怪與一名君王；最多 180 隻敵人及受限粒子/彈幕，以照顧手機效能。樹木是裝飾、不阻擋移動。沒有多人連線、付費商城、任務線、帳號同步、音樂或中途存檔。職業難度不同，遊俠較適合初次挑戰；騎士與法師需更積極走位。畫面與音效完全以程式原創產生。遊戲仍是可持續擴充的第一個可玩版本，而非商業完成品。

### 1.4：看得懂的流派選擇

- 升級卡顯示目前 → 下一階的實際效果；主武器依職業顯示範圍、彈數、貫穿或爆炸差異。只有武器、聖焰環與雷霆誓約第五階標示進化；生命、減傷與攻速滿階不再誤標。
- 暫停選單新增「本局流派」，可查看已取得技能與裝備效果；進化名稱同步顯示在技能列及傷害結算。
- 此版僅改善資訊呈現，不更動戰鬥數值、掉落、存檔格式或八分鐘結算規則。

## 1.5：遺物取捨

任一職業**單局存活至少 60 秒並結算**後，營地解鎖一個遺物欄位；不是累計時間。三種遺物同時開放，免費選擇一件，亦可不裝備。既有符合條件的存檔自動解鎖。

| 遺物 | 效果 | 代價 |
| --- | --- | --- |
| 守望護符 | 抵擋一次敵方飛射攻擊，8 秒充能；不擋近身碰撞 | 移速降低 8% |
| 獵魂羅盤 | 靈魂吸取半徑增加 100 | 出發生命上限降低 15%，四捨五入；後續生命祝福照常 +25 |
| 回響沙漏 | 職業技能冷卻縮短 25% | 每局治療從 3 瓶變成 2 瓶 |

- 遺物在出發時固定，營地或另一分頁改裝不會改變正在進行的角色。暫停不會偷偷充能；重開新局重設護符與職業技冷卻。
- 營地預覽以實際角色引擎計算目前職業／裝備的生命、速度、吸取、職業技冷卻與藥水；暫停流派摘要包含遺物。
- 存檔沿用原有 v1 key，格式升至 schema 2。無版本欄位或 version 1 的舊資料自動遷移，金幣、裝備、最佳生存與勝利紀錄保留；缺少 `relic` 時為不裝備。首次成功寫入前保留有效舊原文備援；儲存失敗不假稱完成。已開啟的 1.4 舊分頁會將 schema 2 視為較新版本並停止寫入，重新整理即可繼續，無需手動搬移。不認識的未來遺物 ID 視為不相容版本，保留原文且停止覆寫。跨分頁選擇、鍛造與結算共用原有安全交易機制。

1.5 的 soak 擴充為 3 職業 × 4 遺物配置（含不裝備）× 3 種子，共 36 場；驗證狀態／記憶體上限與結算，而不是用機器人勝率作人類難度或遺物強弱結論。


## 1.6：實玩稽核與可靠性修正

- 修正窄畫面中「施法者在畫面外，但預警射線穿過玩家」被錯誤裁掉的情況。所有啟動中的預警交由 Canvas 裁切；敵人仍有 180 上限。
- 同一分頁的進度交易整段排隊，包含記憶體更新，避免連按不同鍛造／遺物操作且儲存失敗時，後一項覆蓋前一項尚未存下的進度。單項失敗不會堵住後續交易。
- 普通瀏覽器實玩驗證：第一場騎士在 02:46 死亡，正確呈現飛射死因、212 金幣與裝備；第二場遊俠以正常按鍵、三選一與治療完成真正 08:00 勝利，2,385 擊倒、2,228 金幣、鎧甲 +3。第 7 分鐘首領正常登場，約 07:26 擊倒；回營／重新整理後獎勵只結算一次。
- 實玩是透過 UI 自動操作原本按鍵，沒有注入殺敵、無敵、時間跳躍或假結算。出發時已有武器 +1、鎧甲 +1、守望護符；不代表全新角色零裝備的人類難度測量。
- 程式稽核確認每頁僅一條動畫迴圈，開始／返回營地不重複註冊監聽器；真實長局未觀察到畫面卡死或遊戲程式例外。這不是 FPS、瀏覽器 heap 或實體手機性能認證。
- 背景切換驗證限制：此託管 CUA 瀏覽器在原生畫面選到另一分頁時，原分頁仍回報 `document.hidden=false`／`visibilityState=visible`，因此不能藉此認證實際背景暫停或失焦輸入釋放。程式已處理真實 `blur`／`visibilitychange` 事件，純引擎暫停測試通過；實體瀏覽器背景行為仍需後續驗證，未將工具差異誤報為產品故障。

## 雷焰共鳴 · 技能組合

- 當「聖焰環」與「雷霆誓約」**皆達第 3 階**，啟用「雷焰共鳴」：雷霆誓約施放間隔縮短 10%，從 2 秒改為 1.8 秒；雷霆第 5 階進化後由 1.3 秒縮短為 1.17 秒。
- 未達條件時維持原本傷害、施放次序與冷卻；組合只依照當前升級等級計算，不更動存檔格式或隨機數流程。
- 升級選擇預覽會提示組合解鎖，HUD 顯示組合名稱；暫停畫面的本局流派可檢視組合描述及實際雷霆間隔。
