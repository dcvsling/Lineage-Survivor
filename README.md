# 暮林倖存者 · Lineage Survivor

原創黑暗奇幻瀏覽器生存遊戲，繁體中文介面。以經典奇幻職業與 survivor 自動戰鬥節奏為靈感，**不是《天堂》的官方產品**，未使用其角色、地圖、音樂或美術資產。

## 遊玩

私人線上版：https://lineage-survivor-dcvsling.dcvsling.chatgpt.site （須以擁有者帳號登入）

或在此目錄啟動靜態伺服器：

```sh
python3 -m http.server 8080 --directory dist
# 開啟 http://localhost:8080
```

不需安裝 npm 套件；需現代瀏覽器及支援 ES modules 的 HTTP 伺服器，不能直接以 file:// 開啟。

- **WASD / 方向鍵**：移動。手機使用左下搖桿。
- **自動攻擊**：騎士月鋼斬、遊俠風靈箭、法師追蹤焚星術。
- **Q / 治療按鈕**：恢復 45% 最大生命，每局 3 瓶；滿血不消耗。
- **Esc / 暫停按鈕**：暫停、繼續、放棄返回營地。切離視窗自動暫停。
- 翠綠靈魂提供經驗，升級會停止時間並提供三選一祝福。主武器、聖焰環及雷霆誓約於第五階進化。
- 第七分鐘君王出現；**擊倒君王且存活滿八分鐘**勝利。未擊倒時八分鐘後繼續戰鬥。
- 死亡與勝利均結算：至少擊倒 35 隻魔物可得 +1 裝備、存活四分鐘可得 +2、擊倒君王可得 +3。隨機一個欄位，保留較高階；自動裝備至下一局。武器每階 +8% 傷害、鎧甲每階 +10 生命及減傷 1、戰靴每階 +5 移速。金幣只作戰績紀錄，尚無商店。
- 傳承保存在目前網站來源的 `localStorage`，無伺服器、帳號同步或追蹤。換瀏覽器、換網址或清除網站資料會失去進度。儲存受阻時會提示並保留記憶體中的本次進度。

## 驗證

Node.js 20+：

```sh
npm test
npm run check
```

13 個模擬測試涵蓋：職業差異、移動邊界與正規化、暫停、三選一防重入、進化、有限治療、死亡與重開、裝備、遠程攻擊、固定種子重現、八分鐘效能界線及**正常生命與藥水條件的完整遊俠勝利**。最後一項使用固定種子自動走位測試，不是無敵模式。另有手動瀏覽器 UI 驗證；不是所有手機型號的實機認證。

GitHub Actions 在 push 與 pull_request 執行同一組檢查。不需秘密、外部 API 或後端。

## 結構

- `dist/engine.js`：純 JavaScript、無 DOM 的固定種子遊戲模擬。
- `dist/renderer.js`：原創 Canvas 像素森林、角色、敵人、粒子。
- `dist/main.js`：介面、鍵盤/搖桿、音效、傳承紀錄。
- `dist/style.css`、`dist/index.html`：響應式介面。
- `tests/engine.test.js`：自動化邏輯與八分鐘回歸。
- `.openai/hosting.json`：私人 Sites 靜態部署設定；不含憑證。

## 第一版範圍與限制

單一森林、三職業、三類小怪與一名君王；最多 180 隻敵人及受限粒子/彈幕，以照顧手機效能。樹木是裝飾、不阻擋移動。沒有多人連線、商城、任務線、帳號同步、音樂或中途存檔。職業難度不同，遊俠較適合初次挑戰；騎士與法師需更積極走位。畫面與音效完全以程式原創產生。遊戲仍是可持續擴充的第一個可玩版本，而非商業完成品。
